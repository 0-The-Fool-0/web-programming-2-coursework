# Web Programming 2 Coursework

A private collection of Web Programming 2 labs. Lab directories and distinct variants remain separate; Web Programming 3 is not part of this collection. Lab 9 is excluded because it already has its own GitHub repository.

Source HTML, JavaScript, CSS, templates, static images, package manifests/lockfiles, and non-database JSON data are included. Local `db.json` files, compiled bundles, archives, dependencies, and generated output are excluded. Confirm course permissions, inspect sample data, and review the included-file list before any public release. No dependencies, apps, or tests were run.
