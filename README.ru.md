# Web-программирование 2 — лабораторные работы

[English version](README.md)

Структурированный архив лабораторных по дисциплине «Web-программирование 2». Исходные каталоги и отличающиеся версии сохранены отдельно, а не объединены в одно приложение.

## Что входит

- **HTML/CSS:** макеты страниц, таблицы, адаптивная разметка и статические ресурсы.
- **JavaScript:** работа с DOM, формы, клиентская логика и объектно-ориентированные варианты.
- **Клиент-серверные лабораторные:** небольшие приложения Express для статических страниц и JSON.
- **REST и CRUD:** отдельные лабораторные включают обработчики маршрутов, модуль хранения и манифесты пакетов.
- **Webpack/RxJS:** в лабораторной № 10 есть собственные `package.json`, lock-файл, клиентские ресурсы, Express-сервер и REST-маршруты.

Коллекция разделена на `root collection/` и `repos collection/`. Лабораторная № 9 сюда не включена, так как уже существует отдельный репозиторий: [Web-prog-coure-2](https://github.com/0-The-Fool-0/Web-prog-coure-2). Web-программирование 3 — отдельная дисциплина и в этот репозиторий не входит.

## Запуск лабораторной на Node.js

В корне нет общего Node-пакета и единой команды запуска для всей коллекции. Для лабораторной с `package.json` и `package-lock.json` перейдите в соответствующий каталог и устанавливайте зависимости там.

Например, лабораторную № 10 можно запускать так:

```bash
cd "repos collection/Лаб 10"
npm ci
npm start
```

В манифесте указано, что `npm start` выполняет `node server.js`; команда не запускалась в рамках этого обновления. Статические HTML-лабораторные можно открывать отдельно в браузере.

## Ограничения

Это академическая коллекция, а не одно production-приложение. Для конкретной лабораторной читайте её собственный README и package-манифест. Разные версии сохранены намеренно; сборки и тесты всей коллекции не выполнялись.
